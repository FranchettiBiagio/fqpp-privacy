Informativa sulla privacy

Franchetti QR Photo Pro — ultimo aggiornamento: 9 novembre 2026

English version below

Franchetti QR Photo Pro è un programma locale per fotografi. Non è un servizio cloud e non richiede un account.

Nessuna telemetria

Il programma non invia statistiche, crash report, identificatori o contenuti a Franchetti, a terze parti o a server esterni. Le uniche connessioni di rete sono:

  • il server della galleria, attivo solo sulla rete locale (LAN/Wi-Fi) del computer del fotografo;
  • il server FTP opzionale, anch'esso solo sulla rete locale;
  • i link esterni che l'utente apre volontariamente (per esempio WhatsApp, Facebook, Instagram o il sito del fotografo) dalla galleria.

Non sono presenti pubblicità, tracker o chiamate a servizi di analisi.

Dati sul computer del fotografo

La cartella dati cambia in base al tipo di installazione:

  • versione portatile: data accanto all'eseguibile, se la cartella è scrivibile;
  • installer per singolo utente: data dentro %LOCALAPPDATA%\Programs\FranchettiQRPhotoPro;
  • versione Microsoft Store: %USERPROFILE%\FranchettiQRPhotoPro, perché la sandbox MSIX cancellerebbe i dati in %LOCALAPPDATA% alla disinstallazione.

In questa cartella il programma conserva:

  • impostazioni del programma e del brand (config.json);
  • sessioni, metadati delle foto, database SQLite (fqpp.sqlite3);
  • copie di lavoro in Anteprime, Consegna, cache e exports;
  • log tecnici in logs;
  • statistiche locali di utilizzo della galleria: visite, foto viste, condivisioni, telefoni distinti e orari delle visite.

Queste informazioni restano sul computer e non vengono trasmesse. Le statistiche sono visibili solo al fotografo e possono essere cancellate insieme alla sessione o alla cartella dati.

Originali

Il programma non modifica, sposta o cancella mai i file originali della fotocamera. Le copie scaricabili dai clienti sono generate in cartelle derivate (Anteprime, Consegna) e non contengono GPS; riportano il copyright del fotografo.

Galleria e clienti

La galleria è raggiungibile solo dai dispositivi collegati alla stessa rete locale. I link possono essere protetti da token, scadenza, revoca e permessi per singolo QR. Il fotografo decide quali foto mostrare, se consentire cuori, note, scelte e download e se mostrare i propri contatti (Modalità Pubblicità).

I dati inseriti dai clienti (preferenze, note, richieste di ritocco, scelte) sono salvati nel database locale della sessione e sono visibili solo al fotografo.

Responsabilità del fotografo

Il fotografo è il titolare del trattamento delle foto e dei dati dei clienti. Deve informare le persone fotografate, ottenere i consensi necessari (con particolare attenzione ai minori) e cancellare foto e dati quando non servono più. Il programma mette a disposizione gli strumenti tecnici; non gestisce consensi o richieste di cancellazione al posto del fotografo.

Cancellazione dei dati

Per eliminare tutto:

  1. chiudere il programma;
  2. cancellare la cartella dati indicata sopra (data, oppure %USERPROFILE%\FranchettiQRPhotoPro per la versione Microsoft Store);
  3. se il programma è installato, usare "App e funzionalità" di Windows per rimuoverlo.

La disinstallazione rimuove il programma ma lascia intatta la cartella dati, così le sessioni non vengono perse per errore. La cancellazione dei dati è quindi un'azione esplicita del fotografo.

Privacy policy

Franchetti QR Photo Pro — last updated: 9 November 2026

Franchetti QR Photo Pro is a local desktop application for photographers. It is not a cloud service and does not require an account.

No telemetry

The app does not send statistics, crash reports, identifiers or content to Franchetti, third parties or external servers. The only network connections are:

  • the gallery server, active only on the photographer's local network (LAN/Wi-Fi);
  • the optional FTP server, also local network only;
  • external links the user chooses to open from the gallery (for example WhatsApp, Facebook, Instagram or the photographer's website).

There are no ads, trackers or analytics calls.

Data on the photographer's computer

The data folder depends on the installation type:

  • portable version: data next to the executable, when that folder is writable;
  • per-user installer: data inside %LOCALAPPDATA%\Programs\FranchettiQRPhotoPro;
  • Microsoft Store version: %USERPROFILE%\FranchettiQRPhotoPro, because the MSIX sandbox would delete data in %LOCALAPPDATA% on uninstall.

The app stores settings and brand data, sessions and photo metadata in a local SQLite database, working copies (previews, delivery, cache, exports), technical logs and local gallery statistics. This information stays on the computer and is never transmitted. Statistics are visible only to the photographer and can be deleted with the session or the data folder.

Originals

The app never modifies, moves or deletes the camera originals. Client downloads are generated in derived folders and contain no GPS data; they carry the photographer's copyright.

Gallery and clients

The gallery is reachable only from devices on the same local network. Links can be protected with tokens, expiry, revocation and per-QR permissions. The photographer decides which photos to show and whether to allow hearts, notes, picks and downloads. Client input is stored in the local session database and is visible only to the photographer.

Photographer's responsibility

The photographer is the data controller for photos and client data, and is responsible for informing subjects, obtaining any required consent (especially for minors) and deleting data when it is no longer needed. The app provides technical tools only; it does not manage consent or deletion requests on the photographer's behalf.

Deleting data

To delete everything: close the app, delete the data folder described above, and uninstall the app from Windows "Apps & features" if installed. The uninstaller removes the program but keeps the data folder, so sessions are not lost by accident.
